[h1=简介]

神化属性：分类（Apothic Attributes Categories）是一款面向神化属性（Apothic Attributes）的客户端附属模组，在原版属性界面左侧无缝延展出一套原生风格的分类面板，内置滑块与滚轮支持、支持高度自定义分类与图标路径，并与Apothic Attributes Whitelist零冲突兼容。

{{img:showcase_zh}}

[h1=功能特点]

  • 一体式向左延展面板：与神化属性原界面无缝衔接，配备一致的边框质感、左上角「分类」标题以及 6 格内凹图标列表；鼠标悬停右侧属性时，属性说明框正常显示在最上层不被遮挡。
  • 原生滑块与滚轮支持：左侧提供与右侧风格一致的滚动条轨道与横纹滑块；当可见分类超过 6 个时自动激活，支持按住拖拽滑块、点击轨道跳转以及鼠标滚轮上下滚动。
  • 开箱即用的 7 个默认分类：内置「全部、攻击、防御、生命与生存、移动与采集、魔法与元素、其他」，自动适配原版、神化属性及主流魔法与 RPG 模组的属性。
  • 自定义分类与热重载：修改分类配置文件后重新打开属性界面即可自动热重载，无需重启游戏。
  • 零冲突兼容白名单模组：不覆盖原刷新方法、不冲突注入点，与 Apothic Attributes Whitelist 同时安装时，白名单与黑名单的过滤结果会自动同步到每个分类的属性列表与数量统计中。

[h1=配置文件写法]

[h2=自定义分类（JSON）]

首次打开属性界面后会自动生成 config/apothic_attributes_categories.json（默认已内置全部 7 个分类）以及本地图标目录 config/apothic_attributes_categories_icons/。在 categories 数组中新增、删改或调整条目顺序即可自定义分类，保存后重新打开属性面板即自动生效。

{
  "categories": [
    {
      "id": "elemental",
      "name": "元素伤害",
      "icon": "minecraft:blaze_powder",
      "iconTexture": "minecraft:textures/mob_effect/fire_resistance.png",
      "attributes": [
        "apothic_attributes:fire_damage",
        "apothic_attributes:cold_damage"
      ],
      "namespaces": [
        "irons_spellbooks"
      ],
      "keywords": [
        "elemental",
        "spell"
      ]
    }
  ]
}
字段说明
id分类唯一 ID（小写英文/数字/下划线）。内置保留 ID：all（全部）与 other（未匹配属性的兜底分类）。
name分类显示名称。可直接填写中文或英文文本（如 "元素伤害"），也可填写 "lang:翻译键" 实现多语言切换。
icon物品 ID（如 "minecraft:diamond_sword"），未配置 iconTexture 或贴图不存在时使用该物品图标。
iconTexture可选，优先于 icon，渲染为 16×16 贴图。支持资源包/模组贴图路径（如 "minecraft:textures/mob_effect/strength.png"），也支持将 PNG 放入 config/apothic_attributes_categories_icons/ 目录后填写 "file:my_icon.png" 直接加载。
attributes精确属性 ID 列表（最高匹配优先级）。1.20.1 神化属性命名空间为 attributeslib:，1.21.1/26.1.2 为 apothic_attributes:。
namespaces按模组命名空间归类的列表（次优先级，例如 "irons_spellbooks"）。
keywords按属性 ID 路径关键词归类的列表（不区分大小写，第三优先级）；均未命中时自动归入 other。

[h2=客户端开关（TOML）]

配置文件位于 config/apothic_attributes_categories-client.toml：

配置项默认值说明
enabledtrue是否启用属性界面左侧的分类面板
hideEmptyCategoriestrue是否自动隐藏当前无可见属性的分类（「全部」始终显示）
rememberSelectedCategorytrue重新打开属性面板时是否记住上次选中的分类
showCountInTooltiptrue悬停分类图标时是否在提示中显示该分类下的可见属性数量
